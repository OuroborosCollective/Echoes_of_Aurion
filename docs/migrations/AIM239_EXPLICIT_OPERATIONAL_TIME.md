# Explicit operational time and deterministic decisions

The simulation already uses versioned world seeds, scoped random streams and fixed logical ticks. This change removes the remaining direct Date.now calls/references and zero-argument Date construction from application logic. There are no application-owned Math.random references. Security secrets continue to use cryptographic randomness.

`shared/operationalClock.ts` is the single host I/O adapter. Its host clock contains the one intentional Date.now read. Operational timestamps are checked as nonnegative safe integers within JavaScript's valid date range. Pure deadline calculations, recorded/fixed clocks and explicit observed timestamps enable identical replays. This is a real-time input boundary, not a claim that security expiry or network/capture freshness can run on a frozen world clock. The AST regression scans all client/server/shared runtime source, including aliases, and prevents the native simulation from importing the operational clock.

Guild bank and governance stores accept constructor-injected clocks. SDK signing and cryptographic JWT verification use the same injected source, including the verifier's explicit currentDate; signed tokens still expire and altered signatures still fail. Admin token claims and gateway grant predicates now require an explicit observation time. OIDC discovery can be exercised across its exact cache deadline without waiting. Provider Retry-After values are parsed from a recorded response timestamp; malformed numeric/locale date inputs are rejected, and backoff remains bounded.

Home uses the host adapter for human-input/capture freshness, retaining the existing 1250 ms frame-age validation. DB expiry, presence leases, login lockout and audit timestamps read the same explicit adapter. Audit Date objects are not used to generate gameplay identity, loot or progression.

Validation before CI: 545 local tests pass with 52 database-gated skips; two additional SDK tests pass. TypeScript passes. Tests cover replay with implicit Date.now disabled, invalid/overflowing samples, exact admin/session token boundaries, altered JWT signatures, OIDC cache expiry, HTTP-date retry parsing and the complete runtime source boundary. Added real MariaDB regression proves an unconsumed bank plan expires at exactly 600000 ms without mutation, a plan applies at 599999 ms, and its consumed receipt remains replayable after expiry. Real MariaDB and browser checks are required before merge.
