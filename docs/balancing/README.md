# Balancing

Balancing in diesem Repository ist **Analyse-/Integrationsdokumentation**. Die finalen Gameplayregeln gehören WASD.

- Aurion darf Rechenreports, Candidate JSON und Provenienz speichern.
- AX1 darf bestätigte Werte darstellen.
- WASD entscheidet, welche Formel/Parameter als Gameplayregel versioniert werden.
- Wolfram/CAG, Python oder lokale Replays können Kandidaten prüfen, aber keine Gameplay-Authority erhalten.
