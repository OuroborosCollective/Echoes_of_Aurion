# Experimental Godot tablet login adapter

This is an optional page inside the existing authenticated noVNC service. It does not alter Aurion's authentication backend, create a new endpoint, relax browser isolation, or grant account access.

The existing Godot client creates its normal PKCE transaction. An operator, acting for the owner, forwards only that client's browser URL to the existing VNC clipboard. The page accepts only the canonical Aurion native-login URL, fetches the existing consent form with the browser's existing same-origin cookie, and requires an explicit normal login confirmation. The original CSRF value is posted to its exact native endpoint. The existing backend issues the one-time callback and Godot's unchanged parser, state binding, PKCE exchange and token authority remain mandatory.

This adapter never puts the callback into page history, browser storage, status text or assistant output. The HTTP 303 is followed as a real callback request, so reverse-proxy, access-log and APM query redaction must be independently verified before activation. Browser/VNC/native memory and the existing HTTP service receive the callback; do not claim memory-only handling. A bounded, one-attempt operator helper must deliver it into the existing secret Godot field and clear the clipboard. The helper must never print clipboard text, tokens, state, callback queries or private login images. It must stop on success, failure, expiry or cancellation and must not create another login attempt automatically.

`build_page.py` generates a separate optional HTML page, two adapter modules and a generated noVNC UI copy in a new output directory, without changing a live service. It includes `Referrer-Policy: no-referrer` and a CSP with `connect-src 'self' wss://arelogic.space`, `base-uri 'none'` and `form-action 'self'`. Foreign redirects must be blocked. Existing TLS, Basic authentication and exact WebSocket-origin checks remain unchanged. The standard viewer remains available for rollback. Never enable debug logging on this special login page.

`one_attempt.py` is an operator-run helper, not a daemon or service. It validates the active scene, starts at most one requested native attempt, forwards a callback only into that scene's secret field, and exits within the transaction deadline. It logs only fixed phase labels. It does not verify world rendering; that is a separate required readback.

The helper requires `--expected-pid` from an independent readback. Every operation is pinned to that process and the original scene instance; a replacement native transaction stops the helper. Starting a new transaction additionally requires the explicit `--start-new-attempt` option. A denied probe is never bypassed. This code is not an invitation to run the helper without owner authorization.

## Integration scope

The initial public test branch is based on main `e97a0027d69c6a3a3bf32c3590fdcac38b2d114b`, including PR #1320's diagnostics/recovery fixes and PR #1322's Fadenwerk/quest-editor integration. The nine added files do not overlap either integration or open PRs #1321, #1319, #1317 and #1316 as checked on 2026-11-05. Existing server, Godot, schema, deployment service and auth contracts are unchanged. This optional page is not wired into any release or production workflow. No merge or deployment is part of the test-branch approval.

`browser-proof.mjs` runs disposable browser fixtures in GitHub Actions. Fixture success is not a real user login, a live world, or a tablet-device acceptance result. The authenticated real page, real CSRF/Origin boundary, VNC delivery, native session and confirmed live world must be independently read back before claiming success. If any required stage is unavailable, leave activation pending.

## Activation gates and remaining limitations

The test branch is not approved for activation. The shared VNC clipboard does not identify its sending viewer. PID, scene, request-epoch, state and PKCE checks bind the native process/transaction, but do not prove which viewer confirmed it. Concurrent viewers or connection changes require a separately reviewed exclusive/session-bound transport; counting clients once is not sufficient. No endpoint, cookie or backend authority is changed to work around this.

The page builder fails closed except for the verified noVNC 1.0.0 UI and RFB hashes. It defers all original UI startup until clipboard handlers and warn-only logging are installed, including reconnects. Sending requires the same transaction-bound RFB instance, connected writable state and an open, flushed WebSocket. The UI reports only queuing to VNC. RFB clipboard has no delivery acknowledgement: native authentication and live-world readback remain required.

The workflow also runs Aurion’s unchanged 18 real MariaDB browser/persistence replay and race cases in a disposable localhost-only database, and the pinned Godot native-auth flow, ephemeral-token and HTTP start/exchange/refresh/logout suites in a minimal isolated project. These passed on 9d705b1. They do not exercise the Python operator helper against the real editor, prove viewer/desktop pairing, authenticate a real account, or render a live world. The helper/native handoff remains an activation gate. The production proxy/APM query-log policy must also be verified without examining real callback values.

Real Chromium Basic-auth fixtures confirm that a challenge scoped to `/godot-live/` does not attach Authorization to `/api/native-auth`. A challenge at the host root does attach it; Aurion correctly refuses that header. Do not weaken this rejection or claim compatibility with a wider Basic protection space. The noVNC fixture uses real pinned UI/RFB modules and real loopback HTTP Basic/WebSocket exchanges. Only its Aurion consent fetch is mocked in-page, and external HTTP is blocked. Real canonical Origin, cookie, CSRF, redirect and production CSP behavior is covered separately by offline HTTPS fixtures. The local RFB fixture response omits the production-only CSP because it runs on HTTP loopback, not the deployed HTTPS origin. No combined production end-to-end proof is claimed.
