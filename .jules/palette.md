# UX Learning: Disabled States\n\n- Added `disabled:cursor-not-allowed` (Tailwind) to disabled buttons (like in `Home.tsx` and `Community.tsx`) to provide better visual affordance that an action is currently unavailable.\n- Added `title` attributes on community buttons when they are disabled to give screen readers and hover states contextual explanations (e.g. 'Nur für angemeldete Explorer verfügbar').\n- Kept changes small and utilized existing Tailwind CSS classes, without adding new dependencies or custom CSS.

## 2024-09-12 - [UX] Landing Page & Community Interaction Tactile Feedback
**Learning:** For interactive UI elements (like grids and main action buttons) to feel responsive and premium, applying a subtle hover lift and active scale down improves perceived latency and user satisfaction.
**Action:** Applied Tailwind classes `group hover:-translate-y-0.5 active:scale-95 transition-all` to key buttons and grid links in the Aurion Portal (Home and Community pages). Added `transition-transform group-hover:scale-110` to inner icons. For disabled elements, ensured `disabled:cursor-not-allowed` and explicitly cancelled the transform behaviors using `disabled:hover:translate-y-0 disabled:active:scale-100` to prevent misleading feedback.
